# Public evidence assets

The three PNG files are original, locally rendered views of allowlisted real measurements. They are not unredacted TV screenshots or invented command output. See [the gallery](../docs/gallery.md) and the two JSON files under evidence/ for scope/provenance.

No source identity, private network address, account, key, viewing history, full packet capture or full vendor QML is included. The renderer is [tools/render_gallery.py](../tools/render_gallery.py). Do not replace this allowlist with a generic raw-dump sanitizer.
