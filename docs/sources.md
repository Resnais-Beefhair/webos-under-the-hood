# Source references and evidence boundaries

Device observations in this repository come from the inspected source CX and the allowlisted [public evidence](gallery.md). They are not universal platform guarantees. Original device execution, historical operator records, upstream documentation and offline packaging tests are distinguished in [validation](validation.md).

1. [webOSbrew startup script guide](https://www.webosbrew.org/develop/guides/startup-script). Custom startup location/lifecycle; consult the version you actually run.
2. [AdGuard Public DNS](https://adguard-dns.io/en/public-dns.html). Filtering default IPv4 pair `94.140.14.14` and `94.140.15.15`; not the family-filter pair. Provider policy and behavior can change; choosing it is your explicit recipient decision.
3. [Pinned Homebrew Channel startup implementation](https://raw.githubusercontent.com/webosbrew/webos-homebrew-channel/1a2b969e992617c9ba4b8a891542cb93a9e07b0a/services/startup.sh). Compared with the source TV's script. Relevant to SSH/telnet flags, startup hooks and built-in hosts/spool behavior. This toolkit does not redistribute or patch it.
4. [Pinned SlopBro README](https://raw.githubusercontent.com/throwaway96/slopbro/21023d56ca424607bb03d2939609cc658c655fc7/README.md). Upstream interface and caveats, not proof that an arbitrary TV/firmware is exploitable. The [complete bootstrap guide](rooting.md) includes the operating steps and its own pinned launcher, autoroot, HBC startup/UI and SDK-warning sources; external links are provenance/software downloads, not missing initial instructions.
5. [Homebrew Channel upstream](https://github.com/webosbrew/webos-homebrew-channel). HBC existed before the original maintenance work; the [new bootstrap guide](rooting.md) explains obtaining it through the pinned root operation. Upstream maintains its own licensing and recovery infrastructure.
6. [Root persistence discussion, HBC issue 96](https://github.com/webosbrew/webos-homebrew-channel/issues/96). The upstream warning that startup scripts may not run early enough to block update checks is why this project does not guarantee firmware immutability.

The original investigation also compared a smart-TV privacy demonstration with this older CX. Different-generation lab demonstrations were **not** treated as proof of an exploit, microphone behavior or proxy SDK on this device. That research did not justify disabling Home dependencies or mass-withdrawing consents. This repository is a reproducible maintenance guide, not a claim to have discovered a new LG vulnerability.
